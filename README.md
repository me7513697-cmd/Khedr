# شوارع مصر — نسخة الموبايل (ملفات مسطّحة)

كل الملفات في مكان واحد من غير فولدرات، عشان ترفعها من الموبايل مرة واحدة.
1. ارفع كل الملفات اللي هنا على GitHub (Add file ← Upload files).
2. أنشئ ملف البناء: Add file ← Create new file، الاسم `.github/workflows/build-android.yml`، والصق محتوى ملف build-android.yml.
3. تبويب Actions ← استنى البناء ← تبويب Releases ← نزّل الـ APK.
